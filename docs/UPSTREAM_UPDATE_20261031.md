# 2026-10-31 上游更新说明

本次合入原仓库 `Wei-Shaw/sub2api` 的 86 个更新提交，更新至 `d851a3847`（版本标识 v0.2.19），保留本地已有的 43 个二开提交。

## 用户可以感知的变化

- 新增 MCP 接入，可在支持远程 MCP OAuth 的客户端中登录平台并授权查询或管理资源。默认关闭，需要先配置 `mcp.public_url`，启用后侧栏显示「MCP 接入」。连接、授权和撤销说明见 [MCP 使用文档](mcp.md)。
- 系统设置的「安全」中新增受限管理员访问密钥，可按操作、分组、账户类型及平台分配权限。已有旧版全权密钥保留轮换和删除入口，使用方式见 [管理员访问密钥文档](admin-api-keys.md)。
- 支持 GPT-6.1 Terra；更新 Gemini 默认模型列表，并改进 Grok 模型目录同步与诊断。
- OpenAI、综合分组新增图片按实际出图张数计费的选项，可在启用图片生成后的分组配置中设置。
- 合入 OpenAI Responses 非流式响应兼容、DeepSeek 缓存用量计费、模型列表并发缓存、国产 Coding Plan 频率限流冷却等修复。
- 更新前后端相关依赖，包含 vue-i18n 和 MCP SDK 的上游安全修复。

## 现有二开功能

保留分组默认 Skills 及请求注入、自定义计费单位与订阅用量展示、模型计费页面、充值订阅页面样式、站点 Logo 上传与 URL 配置、错误提示映射、渠道监控重置以及使用记录的代理名称展示等已有实现。

认证缓存版本同步升级，旧缓存将在后续请求中重新加载，同时包含本地默认 Skills 和上游新增的图片计费设置，无需重新创建 API 密钥。

## 更新与使用

本次为本地代码合并，没有推送远程或发布生产环境。重新启动开发服务或部署新构建后使用更新内容；前端依赖已按锁文件安装。

后端启动时会自动执行新增的三个上游迁移：受限管理员密钥、分组图片按张计费及 MCP OAuth。已有迁移保留原文件名与内容；迁移记录按完整文件名识别，同编号的本地和上游脚本可以并存。部署到其他环境前请备份数据库。
